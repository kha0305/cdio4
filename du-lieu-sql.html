File SQL dựng lại toàn bộ cơ sở dữ liệu của hệ thống (xóa cấu trúc cũ, tạo lại 8 bảng, nạp dữ liệu mẫu và tài khoản demo). File này cũng đang chạy trên bản live của thư viện.

Tải file cdio4-full-reset.sql

Sơ đồ bảng CSDL

Sơ đồ các bảng vật lý của CSDL (vẽ bằng dbdiagram.io từ schema SQL thật). Lưu ý: sơ đồ này khác với ERD thiết kế ở Prompt 51 — ERD là mô hình thiết kế, còn đây là các bảng vật lý sẽ tạo trong MySQL.

Tải sơ đồ bảng CSDL (SVG)

Cấu trúc 8 bảng

users — Tài khoản người dùng: admin, thủ thư, độc giả

CộtKiểu / ràng buộc
idINT AUTO_INCREMENT PRIMARY KEY
usernameVARCHAR(50) NOT NULL UNIQUE
password_hashVARCHAR(255) NOT NULL COMMENT 'bcrypt hash (D8)'
full_nameVARCHAR(100) NOT NULL
roleENUM('admin','librarian','reader') NOT NULL
student_codeVARCHAR(20) NULL COMMENT 'chi dung cho reader'
phoneVARCHAR(20) NULL
activeTINYINT(1) NOT NULL DEFAULT 1 COMMENT '1=hoat dong, 0=bi khoa'
created_atDATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP

books — Đầu sách và bản sao, mỗi bản có mã QR riêng

CộtKiểu / ràng buộc
idINT AUTO_INCREMENT PRIMARY KEY
qr_codeVARCHAR(50) NOT NULL UNIQUE COMMENT 'UUID hex 32 ky tu, sinh 1 lan khong doi (D2)'
titleVARCHAR(255) NOT NULL
authorVARCHAR(100) NULL
categoryVARCHAR(100) NULL
publisherVARCHAR(100) NULL
publish_yearINT NULL
cover_urlVARCHAR(500) NULL COMMENT 'Duong dan anh bia, vd /uploads/covers/12-1699999999999.jpg'
book_codeVARCHAR(20) NULL UNIQUE COMMENT 'ma hien thi, vd VH-0001, sinh 1 lan khong doi'
statusENUM('available','borrowed') NOT NULL DEFAULT 'available'
created_atDATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
INDEXidx_books_title (title)
INDEXidx_books_qr (qr_code)

loans — Phiếu mượn / trả sách và tiền phạt

CộtKiểu / ràng buộc
idINT AUTO_INCREMENT PRIMARY KEY
book_idINT NOT NULL
reader_idINT NOT NULL
borrowed_atDATETIME NOT NULL
due_atDATETIME NOT NULL COMMENT 'borrowed_at + loan_days (D4)'
returned_atDATETIME NULL COMMENT 'NULL = chua tra'
fine_amountINT NOT NULL DEFAULT 0 COMMENT 'tien phat (dong), chot luc tra (D7)'
statusENUM('borrowing','returned') NOT NULL DEFAULT 'borrowing'
overdue_notifiedTINYINT(1) NOT NULL DEFAULT 0 COMMENT '1 = da gui thong bao qua han'
created_atDATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
INDEXidx_loans_status (status)
INDEXidx_loans_reader (reader_id)
INDEXidx_loans_due (due_at)

reservations — Đặt trước sách và trạng thái duyệt

CộtKiểu / ràng buộc
idINT AUTO_INCREMENT PRIMARY KEY
book_idINT NOT NULL
reader_idINT NOT NULL
reader_noteVARCHAR(255) NULL COMMENT 'ghi chu gio mong muon den lay cua doc gia'
reserved_atDATETIME NOT NULL
expires_atDATETIME NOT NULL COMMENT 'han duyet: reserved_at + reservation_hours (D11)'
pickup_atDATETIME NULL COMMENT 'lich hen den lay do thu thu chot khi duyet'
reviewed_byINT NULL COMMENT 'id thu thu duyet/tu choi'
reviewed_atDATETIME NULL
reject_reasonVARCHAR(255) NULL COMMENT 'ly do tu choi (optional)'
codeVARCHAR(16) NULL UNIQUE COMMENT 'ma QR dat truoc, 8 ky tu A-Z0-9, sinh khi tao'
statusENUM('pending','approved','rejected','fulfilled','cancelled','expired') NOT NULL DEFAULT 'pending'
created_atDATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
INDEXidx_res_status (status)
INDEXidx_res_book (book_id)

categories — Thể loại sách

CộtKiểu / ràng buộc
idINT AUTO_INCREMENT PRIMARY KEY
nameVARCHAR(100) NOT NULL UNIQUE
codeVARCHAR(10) NOT NULL UNIQUE COMMENT 'ky hieu the loai, vd VH, dung de sinh ma sach'

notifications — Thông báo hệ thống gửi tới người dùng

CộtKiểu / ràng buộc
idINT AUTO_INCREMENT PRIMARY KEY
audienceENUM('all','readers','librarians') NOT NULL DEFAULT 'all' COMMENT 'doi tuong nhan'
typeENUM('reservation','loan','overdue','general','system') NOT NULL COMMENT 'loai thong bao (quyet dinh mau sac)'
titleVARCHAR(255) NOT NULL
bodyTEXT NULL
show_on_landingTINYINT(1) NOT NULL DEFAULT 0 COMMENT '1 = hien dang the noi o landing page'
user_idINT NULL COMMENT 'thong bao rieng cho 1 user (NULL = gui theo audience)'
created_byINT NULL COMMENT 'id admin/thu thu tao (NULL = he thong tu dong)'
created_atDATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
INDEXidx_notif_audience (audience)
INDEXidx_notif_type (type)
INDEXidx_notif_created (created_at)

notification_reads — Trạng thái đã đọc của từng thông báo

CộtKiểu / ràng buộc
notification_idINT NOT NULL
user_idINT NOT NULL
read_atDATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP

settings — Cấu hình hệ thống: số ngày mượn, mức phạt, số cuốn tối đa, giờ giữ chỗ

CộtKiểu / ràng buộc
idINT PRIMARY KEY COMMENT 'luon = 1, chi 1 dong cau hinh'
loan_daysINT NOT NULL DEFAULT 14 COMMENT 'so ngay duoc muon (D3)'
fine_per_dayINT NOT NULL DEFAULT 5000 COMMENT 'phat moi ngay tre, dong (D3)'
max_books_per_readerINT NOT NULL DEFAULT 5 COMMENT 'so cuon toi da cung luc (D3)'
reservation_hoursINT NOT NULL DEFAULT 48 COMMENT 'so gio giu sach khi dat truoc (D11)'
