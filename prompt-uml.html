MANDATORY DRAWING CONVENTIONS (apply to every prompt)

Sequence diagram — exactly 5 lifelines

Order from left to right, do NOT add or remove any: 1. Actor — the user (state the role explicitly: Thủ thư / Độc giả / Admin). 2. Giao diện — the React page (e.g. BorrowPage, LoginPage). 3. Form — the form/modal/input control on that page (e.g. the login form, the add-book form, the search box, a tab). 4. Hệ thống — the entire backend merged into one (Controller + Service + Repository). Detailed function names are still written in full on the arrows, using the pattern Hệ thống: ServiceName.functionName(params). 5. CSDL — MySQL (state the table and the operation explicitly: SELECT / INSERT / UPDATE which table).

Activity diagram — exactly 4 swimlanes

Actor | Giao diện | Hệ thống | CSDL. Place every activity and every decision node in the correct lane: - Actor: user actions (clicking buttons, entering data, scanning QR codes). - Giao diện: rendering pages/forms/notifications, navigation. - Hệ thống: data validation, business logic, code generation, calculations. - CSDL: all data read/write operations.

Class diagram

Keep the stereotypes <<boundary>> (page), <<control>> (controller), <<entity>> (entity).
